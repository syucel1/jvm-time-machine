# tm-ui

Browser UI for JVM Time Machine: timeline scrubber, flame graphs, time diff and request views.

**Status:** placeholder. The UI is built in **Phase 4 (Timeline UI)** as a Vite + React + TypeScript
project with Canvas/WebGL rendering, and bundled into `tm-cli`. It is not a Gradle module.

See [DESIGN.html](https://syucel1.github.io/jvm-time-machine/DESIGN.html#ui) for why the UI runs in
the browser rather than Swing.
